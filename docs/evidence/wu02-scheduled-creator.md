# Work Unit 2 — Scheduled creator

## Result

Implemented an AndroidX-free scheduled-match creator contract and a JVM procedural
creator. It uses public alpha18 `RemoteComposeWriter` and `JvmRcPlatformServices`;
no Compose capture or device playback was started.

`PayloadEnvelope.sha256` is SHA-256 of the exact defensive payload bytes, rendered
as lowercase hexadecimal. The envelope is not included in that hash. Signing is
metadata only: `EXTERNAL_SIGNATURE_REQUIRED` and `hasSignature == false` do not
claim a signature or manage keys.
